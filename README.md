
# Agnelo Tomé — Portfólio

Portfólio pessoal desenvolvido para apresentar a minha trajetória como **Desenvolvedor Full Stack**, destacando competências técnicas, projetos desenvolvidos e experiências na área de desenvolvimento.

O objetivo é apresentar o meu trabalho de forma simples, moderna e intuitiva, permitindo conhecer as minhas competências e explorar alguns dos projetos em que participei.

## Tecnologias utilizadas

- **React** — construção da interface.
- **TypeScript** — tipagem estática e maior segurança no desenvolvimento.
- **Vite** — ambiente de desenvolvimento e build.
- **Tailwind CSS** — estilização e criação de interfaces responsivas.
- **React i18next** — internacionalização e suporte a múltiplos idiomas.
- **Lucide React** — biblioteca de ícones.
- **ESLint** — análise estática e padronização do código.

## Funcionalidades

- Apresentação pessoal e profissional.
- Secção de competências técnicas organizadas por categorias.
- Portfólio de projetos com descrições e tecnologias utilizadas.
- Acesso aos repositórios e demonstrações dos projetos.
- Suporte aos idiomas português e inglês.
- Interface responsiva, adaptada a diferentes dispositivos.
- Animações e elementos visuais para melhorar a experiência de navegação.

## Executar localmente

### 1. Clonar o repositório

```bash
git clone https://github.com/AgneloTome13/agnelo-portfolio.git
```

### 2. Entrar na pasta do projeto

```bash
cd agnelo-portfolio
```

### 3. Instalar as dependências

```bash
npm install
```
